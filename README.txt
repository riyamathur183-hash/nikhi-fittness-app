BEAST FITNESS TRACKER – iPhone install

This is an installable web app (PWA), not an App Store IPA.
To add it to an iPhone Home Screen, the files must first be hosted at an HTTPS address.

Easy hosting option:
1. On a computer, create a GitHub repository and upload all four files from this folder:
   index.html, manifest.json, sw.js, icon-192.png
2. In the repository Settings -> Pages, enable deployment from the main branch / root.
3. Open the resulting https://...github.io/... link in Safari on your iPhone.
4. Tap Share -> Add to Home Screen -> Add.

The app stores checklist, water, workout, notes and weight entries in the browser's local storage on that device. It does not sync between devices. Nutrition figures are estimates and assumptions are stated inside the app.
